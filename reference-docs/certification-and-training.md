# Certification and Training

Every consultant who configures OPERA Cloud for a client should hold a current Oracle Hospitality credential. This page sets the rule, the path and the renewal cycle. Verified 23 September 2026.

## The rule

1. No consultant leads a configuration workstream without a current OPERA Cloud credential.
2. Credentials are tracked centrally with earned date, expiry date and exam version.
3. Renewal starts three months before expiry, not after.

## Validity (documented)

Oracle states: "Oracle Cloud Applications certifications are valid for 18 months from the date the credential is earned." Source: [Oracle Certification Program Guidelines](https://www.oracle.com/education/certification/guidelines/).

Oracle also retires versioned exams on a fixed schedule. A 2025 credential can retire before 18 months have passed when Oracle publishes the next version. Treat the shorter of the two dates as the expiry.

Correction worth knowing: the renewal cycle for cloud application credentials is 18 months, not two years.
