# Oracle OPERA Cloud Training Course Catalogue

Source: Oracle OPERA Cloud Training Courses official list.

## Configuration courses

These courses cover the build-side of OPERA Cloud. Typically taken by implementation consultants, super-users, and IT during pre-go-live.

1. Oracle Hospitality OPERA Cloud Identity and Access Management
2. Oracle Hospitality OPERA Cloud Configuration: Property Setup
3. Oracle Hospitality OPERA Cloud Configuration: Rooms & Inventory
4. Oracle Hospitality OPERA Cloud Configuration: Financial Management
5. Oracle Hospitality OPERA Cloud Configuration: Rate Management
6. Oracle Hospitality OPERA Cloud Configuration: Reservations & Bookings
7. Oracle Hospitality OPERA Cloud Configuration: Profiles & Client Relations
8. Oracle Hospitality OPERA Cloud Sales and Event Management (OSEM) Configuration

15. Oracle Hospitality OPERA Cloud Commission Handling

## Recommended sequencing for new property go-live

### Week 1 (Configuration team only)
- Identity and Access Management
- Property Setup
- Rooms & Inventory

### Week 2 (Configuration team)
- Financial Management
- Rate Management
- Reservations & Bookings

### Week 3 (Configuration team + super-users)
- Profiles & Client Relations
- OSEM Configuration (if applicable)
- Interfaces
- OPI

### Week 4 (All operational staff)
- Getting Started with OPERA Cloud
- Profiles and Reservations
- Front Office and Cashiering
- Housekeeping
- Accounting/Finance
- Group Sales and Events (if applicable)
- OSEM (if applicable)
- Commission Handling
- Reporting and Analytics
- Reporting

## Tiago notes

- The official catalogue has 20 courses. For most EMEA chain rollouts, the 40-hour, 5-day training schedule covers courses 9 through 16, with 17 and 18 added for the interface owner.
- Reporting and Analytics (19) and OPERA Cloud Reporting (20) overlap. R&A is the cloud analytics layer, the latter is the in-product reporting. Decide which the property uses before scheduling.
- OSEM courses (8 and 16) are skipped for PMS-only properties. Verify the property scope before booking trainer time.
- Identity and Access Management (1) is the most under-trained course and the most often blamed when go-live fails. Make sure the property has at least one trained admin before cutover.
- For partner-supported properties, the trainer typically covers operational courses on-site over 5 days. Configuration courses are usually self-paced via Oracle University before the trainer arrives.
