# Front Desk Operations Complete Reference

Comprehensive procedures for guest check-in, check-out, room assignment, and daily front desk management in OPERA Cloud.

---

## Overview

Front Desk Operations manages all guest interaction workflows:
- Guest check-in and check-out
- Room assignment and moves
- Guest communication
- Folio management
- Daily front desk tasks

**Sections:**
1. Check-In Procedures
2. Check-Out Procedures
3. Room Assignment
4. Guest Communication
5. Daily Front Desk Management

## 1. CHECK-IN PROCEDURES

### Pre-Arrival Setup

Before guest arrives:

1. **Verify Reservation**
   - Menu: Client Relations → Reservations → Search Reservations
   - Enter guest name or confirmation number
   - Confirm check-in date matches today
   - Review special requests in reservation notes

2. **Review Guest Profile**
   - Click guest profile link
   - Check VIP status, loyalty membership
   - Review preferences (smoking, floor, view)
   - Check payment method and payment guarantee

3. **Check Room Status**
   - Menu: Front Desk → Room Management → Room Status
   - Verify assigned room is Clean/Ready
   - If room not ready, contact Housekeeping
   - Check for maintenance flags

### Check-In Steps

**Menu Path:** Front Desk → Check-In Guest (or from Reservation search)

**Step 1: Retrieve Reservation**

1. Click **Check-In Guest** or search reservation
2. Confirm reservation details:
   - Guest name, arrival/departure dates
   - Room type assigned
   - Rate code and nightly rate
   - Number of guests
   - Special requests/notes

**Step 2: Verify Guest Identity & Payment**

1. Ask guest for government-issued ID
2. Verify identity matches reservation
3. If credit card required:
   - Swipe card or enter manually
   - Get authorization for guarantee amount (usually 1-2 nights + taxes + incidentals)
   - Process and confirm authorization
4. If prepaid:
   - Verify payment already received
   - Skip card processing

**Step 3: Review Folio & Charges**

1. Click **Folio** to review:
   - Room rate (nightly breakdown)
   - Taxes
   - Automatic charges (resort fee, parking)
   - Pre-authorized charges
2. Explain charges to guest
3. Point out checkout time (usually 11 AM)

**Step 4: Assign Room (If Not Pre-Assigned)**

1. System may auto-assign or allow selection
2. Consider:
   - Guest preferences (floor, view, location)
   - Room upgrades (if available and policy allows)
   - Room hierarchy rating (if using room assignment ratings)
3. Confirm room number verbally

**Step 5: Key Card Issuance**

1. Process key card activation:
   - Swipe blank key card in reader
   - System encodes with room number and dates
   - Card becomes active upon check-in completion
2. Hand key to guest
   - Explain card opens room, front door, and amenities
   - Warn card is programmed to deactivate at checkout
   - Offer duplicate card if requested (may have fee)

**Step 6: Guest Orientation**

Provide information:
- Room location and how to access (elevator, stairs)
- WiFi network name and password
- Parking location/code
- Restaurant/bar hours and locations
- Gym/pool hours
- Emergency procedures (fire exits, emergency contact)
- Checkout time and process
- Bellhop/concierge contact

**Step 7: Complete Check-In**

1. Click **Complete Check-In** or **Confirm**
2. System processes check-in:
   - Reservation converts to folio
   - Room status changes to Occupied
   - Guest room access activated
   - Welcome email sent (if configured)
3. Provide guest with:
   - Welcome packet
   - Key cards
   - Hotel information sheet
   - Local area map/guide
   - Business card with front desk number

### Early Check-In

If guest arrives before standard check-in time (e.g., noon):

1. Check room status - if Clean/Ready, allow check-in
2. If room not yet cleaned:
   - Offer luggage storage while room is prepared
   - Offer early access to lobby/lounge
   - Notify Housekeeping to prioritize
   - Call guest to room when ready
3. No additional charge (unless hotel policy charges for early check-in)

## 2. CHECK-OUT PROCEDURES

### Late Checkout Requests

Guest requests to stay past standard checkout time:

1. **Check Availability**
   - Menu: Front Desk → Room Management → Room Status
   - See if next arrival is in room
   - Check if housekeeping can accommodate

2. **Approve or Deny**
   - **Same-day turnover rooms:** Usually deny (housekeeping needs time)
   - **No arrival today:** Usually allow (free late checkout)
   - **Manager approval required:** If guest has extended stay or high loyalty status

3. **Process Late Checkout**
   - Update reservation with new checkout time
   - Add late checkout charge if applicable (e.g., $25-50 fee)
   - Notify housekeeping of new departure time
   - Communicate new checkout time to guest

### Check-Out Steps

**Menu Path:** Front Desk → Check-Out Guest

**Step 1: Retrieve Folio**

1. Search guest by room number or name
2. Review all charges:
   - Room charges
   - Taxes
   - Food & beverage
   - Parking
   - Resort fees
   - Phone calls
   - Miscellaneous charges
3. Ask guest if they have questions about charges

**Step 2: Address Disputes (If Any)**

If guest disputes a charge:
1. Review charge detail
2. Verify charge was authorized
3. If charge is legitimate:
   - Explain reason for charge
   - Direct to itemized folio for detail
4. If charge is erroneous:
   - Remove charge
   - Apologize for error
5. If guest still disputes:
   - Offer to escalate to manager
   - Document dispute reason
   - Keep folio open pending investigation

**Step 3: Payment Processing**

1. **Credit Card on File**
   - Present folio with total amount due
   - Swipe card already authorized
   - Obtain signature (if required by payment processor)
   - Provide receipt

2. **New Payment Method**
   - Ask how guest wishes to pay
   - Process payment (card, cash, check)
   - Verify payment clears/approves
   - Provide receipt

3. **Bill to Company Account**
   - Verify account number
   - Enter direct bill code
   - Generate invoice for accounting
   - Provide copy to guest

**Step 4: Return Key Cards**

1. Ask guest to return all key cards
2. Count cards:
   - Original card
   - Duplicate cards (if any)
3. If card not returned:
   - Ask guest to check room/car
   - If still missing, card will deactivate at checkout (no additional charge)

**Step 5: Final Items**

1. Ask guest if they left anything in room/safe
2. Offer safe deposit return if guest used hotel safe
3. Ask about room condition/maintenance issues
   - Note any damage for billing
   - Thank guest for reporting issues

**Step 6: Complete Checkout**

1. Click **Complete Check-Out** or **Finalize**
2. System processes checkout:
   - Finalizes folio
   - Closes room access
   - Changes room status to Dirty (housekeeping to clean)
   - Generates bill/invoice
3. Provide to guest:
   - Final folio/receipt
   - Thank you card
   - Feedback survey (optional)
   - Frequent stay card (if applicable)

**Step 7: Post-Checkout**

1. Wish guest safe travels
2. Invite return visit
3. Flag any issues (damaged furniture, missing items) for management review
4. Ensure room is ready for housekeeping

### Express Checkout

Guest checks out without visiting front desk:

**Setup:**
1. Previous night: Offer express checkout option
2. Guest indicates:
   - Credit card will be charged folio as-is
   - No room inspection needed
   - Key card left in room or with housekeeping

**Process:**
1. Guest departs, leaves key card
2. Front desk finalizes folio automatically
3. Charge posts to credit card on file
4. Email receipt to guest
5. Room released to housekeeping

## 3. ROOM ASSIGNMENT

### Room Status Levels

| Status | Meaning | Assignable? |
|--------|---------|-------------|
| Clean | Ready for guests | Yes |
| Dirty | Needs cleaning | No |
| Occupied | Guest in room | No |
| Out of Order | Maintenance issue | No |
| Out of Service | Temporary unavailable | No |
| Inspected | Cleaned and verified | Yes |

### Room Assignment Rules

**Preferences (in order):**
1. Guest preferences from profile (smoking, floor, view)
2. Room upgrade path (Standard → Deluxe → Suite)
3. Room feature match (accessibility, balcony)
4. Room maintenance status (prefer rooms not recently serviced)
5. Physical location (near elevator, away from elevator)

**Restrictions:**
- Do NOT assign out-of-order rooms
- Do NOT assign occupied rooms
- Do NOT assign rooms below guest tier if higher available
- Honor smoking restrictions (many hotels non-smoking only)

### Manual Room Assignment

If automatic assignment doesn't work:

**Menu Path:** Front Desk → Room Assignment

1. Select guest/reservation
2. View available rooms by:
   - Room type
   - Floor
   - Feature (smoking, accessibility)
   - Rate (room upgrade pricing)
3. Click room to assign
4. Confirm assignment
5. Guest can now check in to assigned room

### Room Move (During Stay)

Guest requests room change:

1. **Determine Reason**
   - Noise complaint (move away from elevator/ice machine)
   - Maintenance issue (AC broken, water damage)
   - Upgrade request (pay difference for better room)
   - Special request (forgot accessibility need)

2. **Check Availability**
   - Menu: Front Desk → Room Management → Available Rooms
   - Verify room is Clean/Ready
   - Confirm no conflicts with next arrival

3. **Process Move**
   - **Menu Path:** Front Desk → Room Move
   - Select guest current room
   - Select new room
   - Decide: Charge for upgrade or complimentary
   - Click **Move**
   - System updates:
     - Old room back to Dirty status
     - New room assigned to guest
     - Key cards activated for new room
     - Folio updated with move record
     - Housekeeping notified

4. **Guest Relocation**
   - Provide new key card
   - Offer housekeeping assistance if needed
   - Apologize for inconvenience (if service recovery)

## 4. GUEST COMMUNICATION

### Messages (Templates)

**Menu Path:** Front Desk → Guest Messages

Pre-configured messages for common situations:

- "Guest in lobby"
- "Guest has phone call"
- "Guest has visitor"
- "Wake-up call requested"
- "Fax received"
- "Package arrived"

### Phone Extensions

Typical front desk phone extensions:
- 0 = Front Desk
- 1 = Housekeeping
- 2 = Maintenance
- 3 = Restaurant
- 4 = Bar
- 5 = Room Service
- 6 = Concierge
- *55 = Guest services (some properties)

### Wake-Up Calls

Request:
1. Guest calls front desk: "I need a wake-up call at 7 AM"
2. Front desk logs call:
   - Room number
   - Time requested
   - Preferred method (phone call or knock on door)
3. Set reminder/alarm
4. Call guest at requested time
5. Confirm guest is awake before hanging up

### Guest Requests Log

Maintain record of:
- Special requests from reservation
- Additional requests made at check-in
- Maintenance issues reported
- Guest complaints/concerns
- Amenities provided (late checkout, room upgrade)

## 5. DAILY FRONT DESK MANAGEMENT

### Opening Shift Checklist

1. **System Check**
   - Log into OPERA
   - Review night audit report from previous shift
   - Check for any system issues or error messages

2. **Message Review**
   - Check for guest messages waiting
   - Check for maintenance work orders
   - Review wake-up calls scheduled

3. **Room Status Review**
   - Menu: Front Desk → Room Status Summary
   - Confirm all Occupied rooms are correct
   - Check for Dirty rooms (housekeeping should be cleaning)
   - Note Out-of-Order rooms

4. **Arrivals Today**
   - Menu: Front Desk → Today's Arrivals
   - Pre-assign rooms if not already assigned
   - Prepare key cards for expected arrivals
   - Notify housekeeping of room assignments

5. **Departures Today**
   - Menu: Front Desk → Today's Departures
   - Flag late checkout requests
   - Prepare checkout folios
   - Notify housekeeping of check-out timeline

### Closing Shift Checklist

1. **Guest Folios**
   - Review any open folios
   - Note any disputed charges for manager review

2. **Messages & Requests**
   - Process any outstanding guest requests
   - Note recurring issues for management

3. **Room Inventory**
   - Final room status count
   - Confirm all occupied rooms assigned
   - Note any maintenance issues

4. **Revenue & Occupancy**
   - Menu: Front Desk → Occupancy Report
   - Confirm room count and revenue
   - Flag any discrepancies

5. **Handoff Notes**
   - Write notes for night shift
   - Flag any guest issues or VIPs
   - Note arrival/departure timeline

### Guest Satisfaction Triggers

High-priority situations requiring manager attention:

- Guest complaint about room condition
- Guest disputes charge
- Maintenance emergency (AC, plumbing, electricity)
- Security/safety concern
- Guest feeling unwell
- Lost or stolen items
- Guest threatening to leave negative review

**Response:**
1. Escalate to manager immediately
2. Offer service recovery (room upgrade, meal credit, discount)
3. Document conversation and resolution
4. Follow up with guest before departure

## Best Practices

1. **Greeting** - Welcome each guest with a smile and eye contact
2. **Speed** - Process check-in/out efficiently but not rushed
3. **Accuracy** - Verify all guest information carefully
4. **Communication** - Explain all charges and policies clearly
5. **Problem-Solving** - Address issues immediately; escalate if needed
6. **Security** - Verify ID for all check-ins; never give guest information to strangers
7. **Personalization** - Use guest name, remember preferences for repeat guests
8. **Recovery** - Fix mistakes quickly with service recovery (free breakfast, late checkout, upgrade)
